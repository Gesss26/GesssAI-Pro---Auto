# ⚽ GesssAI-Pro v3.0

**Scraper automatico FBref + App di analisi scommesse**

## 🚀 Funzionalità

- **Scraping automatico** da FBref ogni 6 ore
- **Analisi statistica** con Monte Carlo + Poisson
- **Loghi squadre** integrati (auto-download)
- **Heatmap per campionato** con percentuali giocate
- **Schedina interattiva** con selezione famiglie
- **API REST** per integrazioni

## 📦 Installazione

```bash
# Clona repository
git clone https://github.com/tuo-username/gesssai-pro.git
cd gesssai-pro

# Installa dipendenze
npm install

# Scarica loghi (opzionale)
npm run download-logos

# Avvia server
npm start
